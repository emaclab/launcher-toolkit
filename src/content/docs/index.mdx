## Start with one command

Install the toolkit once, then create a project:

```powershell
launcher-toolkit init my-game
cd my-game
launcher-toolkit dev
```

Choose a **minimal** or **complete** starter. Both use plain CSS, include the required pack files,
and come with a Windows build workflow. No separate template access, Studio executable, Rust,
Node.js, or npm installation is needed.

## Check and build

```powershell
launcher-toolkit check
launcher-toolkit build
```

Build runs complete checks before creating the pack. Errors stop it; warnings remain visible.
The project records its tool version in `.toolkit-version`, and CI uses that same release.
Tailwind is optional and downloaded by the toolkit only when the project uses it.

<Aside type="caution" title="Preview limitations">
The current game download, installation, anti-cheat status, and game start are simulated.
Use these controls to test presentation. They do not install or start a game client.
</Aside>

Starters are public downloads with a [restricted license](/launcher-toolkit/getting-started/starters/#license),
for games integrated with EMAC Anti-Cheat. Retain their license notices.
